## Objetivo de la práctica

Elaborar un Business Model Canvas de una aplicación multiplataforma con Archify, organizar sus nueve componentes de negocio y analizar el proceso de revisión y mejora de prompts. Documentar los resultados distinguiendo la evidencia disponible de la información pendiente.

## Descripción y justificación de Netflix

Netflix se aborda como una aplicación de entretenimiento por Internet cuyo modelo combina contenido audiovisual, tecnología y suscripciones. El Canvas disponible contempla Android, iOS/iPadOS, computadoras mediante navegador, Smart TV, consolas y reproductores multimedia compatibles.

Su elección permite analizar una experiencia multiplataforma: el modelo relaciona diferentes pantallas con el acceso al catálogo, la personalización por perfiles y la continuidad de reproducción. También permite identificar socios, recursos, actividades, costos e ingresos dentro de los nueve bloques del Canvas.

El entregable aclara que el catálogo, las descargas y otras prestaciones dependen del país, el plan y el dispositivo. Estas descripciones reflejan el enfoque del modelo educativo disponible.


## Descripción del modelo final

El [modelo final](canvas/business_model_canvas_netflix.html) es un HTML autónomo en español que se identifica como versión final y presenta los siguientes bloques:

| Bloque | Contenido del entregable |
| --- | --- |
| Socios clave | Productoras, estudios, titulares de derechos, talento creativo, fabricantes, operadores de Internet y socios publicitarios. |
| Actividades clave | Producción y licenciamiento, desarrollo de aplicaciones, distribución de video, recomendaciones, marketing y publicidad. |
| Recursos clave | Catálogo y derechos, nube, Open Connect, aplicaciones, sistemas de recomendación, marca y equipos. |
| Propuesta de valor | Entretenimiento en múltiples pantallas, continuidad, variedad, personalización, flexibilidad y descargas compatibles. |
| Relaciones con clientes | Perfiles, recomendaciones, autoservicio, atención al cliente y controles parentales. |
| Canales | Aplicaciones móviles, web, aplicaciones para TV y otros dispositivos, campañas y socios. |
| Segmentos de clientes | Suscriptores, usuarios del hogar, aficionados al contenido, usuarios multiplataforma, usuarios según presupuesto y anunciantes. |
| Estructura de costos | Contenido, tecnología, marketing y operación. |
| Fuentes de ingresos | Suscripciones, planes, publicidad y miembros extra donde corresponda. |

El CSS utiliza tarjetas, una paleta roja y temas claro y oscuro. Define una cuadrícula Canvas para pantallas amplias y reglas para reorganizar el contenido en dos columnas y después en una columna al reducir el ancho.

El código implementa selección de tarjetas, eliminación de la selección mediante un botón o la tecla `Escape`, apartados «Ver contexto», cambio de tema y apertura del diálogo de impresión. Incluye indicadores de foco, atributos de accesibilidad y una región de estado para anunciar el bloque seleccionado.

La sección «Alcance y fuentes de referencia» contiene enlaces a recursos oficiales de Netflix y un informe anual. Se comprobó su presencia en el código; esta revisión no verifica de forma independiente su contenido ni la fecha de consulta declarada. El Canvas es una interpretación educativa, no un documento oficial de Netflix.
